# Mahra Importados — Links Oficiais

Página de links da bio do Instagram [@mahra.br](https://www.instagram.com/mahra.br).

- Todo o site está no arquivo `index.html` (a logo já vem embutida nele).
- Para mudar um link ou texto: abra o `index.html`, procure o botão pelo comentário (ex.: `Botão 1: WhatsApp`) e altere o `href` ou o texto.
- Cores: bloco "CORES DA MARCA" no início do arquivo.
